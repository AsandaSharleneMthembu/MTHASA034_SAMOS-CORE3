| Folder / file | Description |

## Running the notebooks

The notebooks are written for Python 3 and use the standard scientific stack: `numpy`, `pandas`, `xarray`, `matplotlib` and `cartopy`.

```bash
pip install numpy pandas xarray matplotlib cartopy jupyter
jupyter notebook
```
